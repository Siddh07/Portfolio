# React Portfolio

Modern React portfolio built with Vite, featuring smooth animations, responsive design, and optimized for GitHub Pages deployment.

## 🚀 Features

- ⚡ Built with Vite for lightning-fast development
- ⚛️ React 18 with modern hooks
- 🎨 Responsive design that works on all devices
- 📱 Mobile-friendly navigation
- 🔍 SEO optimized with React Helmet
- 📊 Google Analytics integration
- 🎯 Smooth scroll navigation
- ⌨️ Typing animation effect
- 🚀 Automatic deployment to GitHub Pages

## 🛠️ Tech Stack

- React 18
- Vite
- React Scroll
- React Typed
- React Helmet Async

## 📦 Installation

```bash
npm install
```

## 🏃 Development

```bash
npm run dev
```

Visit `http://localhost:5173` to see your portfolio.

## 🏗️ Build

```bash
npm run build
```

## 🚀 Deployment

This project is configured for automatic deployment to GitHub Pages using GitHub Actions.

### Setup:

1. Push your code to GitHub
2. Go to repository Settings → Pages
3. Under "Build and deployment", select "GitHub Actions" as the source
4. Push to main branch to trigger deployment

Your site will be available at: `https://siddh07.github.io/Portfolio/`

## 🎨 Customization

### Update Personal Information

Edit the component files in `src/components/` to update:
- **Header.jsx**: Name, title, social links
- **About.jsx**: Bio and interests
- **Education.jsx**: Education and certifications
- **Experience.jsx**: Work experience
- **Projects.jsx**: Portfolio projects
- **Skills.jsx**: Technical skills
- **Links.jsx**: Social media links

### Update Styles

- `src/App.css`: Component-specific styles
- `src/index.css`: Global styles and utilities

### Update Assets

Replace files in `public/assets/img/` with your own images.
